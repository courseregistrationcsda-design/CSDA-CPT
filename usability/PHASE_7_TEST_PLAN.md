# Phase 7 Moderated Usability Test Plan

## Purpose

Validate whether real staff and a mobile-first user can complete the toolkit’s critical workflows without assistance. This is evaluation of the interface, not the participant.

## Participants

Run five separate sessions:

1. Enrollment staff member A
2. Enrollment staff member B
3. Administrator
4. Trainer
5. Mobile-first user

Do not use real student, guardian, payment, or receipt information.

## Session length

Allow 35–45 minutes per participant:

- 5 minutes: introduction and consent
- 25–30 minutes: tasks
- 5–10 minutes: debrief

## Facilitator introduction

> We are testing the CSDA Pricing Toolkit, not you. Some parts may be unclear; that is useful evidence for us. Please think aloud and say what you expect before clicking. You may stop at any time. Use only the fictional information provided. We will record task outcomes and observations, not passwords or real personal information.

Ask permission before recording audio/video. Do not record the screen if real notifications or unrelated personal information may appear.

## Core tasks

### Task 1 — Find and review a course

Find “Core 1 — Artistic Essentials,” open its outline, and explain what you would do next to prepare a quote.

Observe search use, course-detail discovery, close behavior, and confidence.

### Task 2 — Prepare a quote

Create a quote containing three eligible regular courses. Check available discounts and select Early Bird. Explain the final amount and payment plan.

Observe whether combined discount/price controls are understood.

### Task 3 — Adult enrollment

Enroll fictional adult learner Mara Reyes using the synthetic-data sheet. Complete all six steps, save, return, then finalize and create a PDF.

Observe progress bar, Emergency Contact wording, schedule edits, final-action distinction, and errors.

### Task 4 — Minor enrollment

Enroll fictional minor learner Nico Santos. Confirm that wording changes to Parent / Legal Guardian and complete required consent using synthetic details.

Observe age recognition, consent discoverability, and legal-tab completion.

### Task 5 — Facility session

Open Shared Service Facility, select a free workstation, start a 1.5-hour session, add 30 minutes, and explain how to end and bill it.

Observe permanent split layout, workstation state, and right-panel hierarchy.

### Task 6 — Administrator and backup

Open Administrator, explain the security warning, locate backup status, and download a full backup. Do not change the production password during testing.

Observe understanding that the password is a workflow gate and where records are stored.

### Role-specific extension

- Administrator: edit a test course price, cancel, then safely reset/correct the draft.
- Trainer: locate the catalogue CSV and explain how modules/lessons would be returned.
- Mobile-first user: repeat Tasks 1, 2, and 5 at phone width and identify any clipped or difficult control.

## Intervention rule

Wait at least 20 seconds before assisting. Record the exact point of confusion and the smallest prompt given. A task requiring facilitator instruction is not an unassisted success.

## Debrief questions

1. What felt easiest?
2. What felt risky or unclear?
3. What did you expect Save to do?
4. What did you expect Finalize and create PDF to do?
5. Where do you think records are stored?
6. Which screen would you change first?
7. On a 1–5 scale, how confident would you feel using this with a real enrollment?
