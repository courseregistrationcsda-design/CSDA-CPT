# Facilitator Session Checklist

## Before

- [ ] Use a test browser profile or backed-up test device
- [ ] Confirm no real CSDA records are visible
- [ ] Load the synthetic test-data sheet
- [ ] Prepare timer and observation sheet
- [ ] Confirm participant role and device category only; do not record their name
- [ ] Obtain permission for any recording

## During

- [ ] Read the neutral introduction
- [ ] Ask participant to think aloud
- [ ] Start timing each task
- [ ] Record errors, backtracking, assistance, and confidence
- [ ] Wait 20 seconds before prompting
- [ ] Never enter real personal or payment information
- [ ] Do not interpret local counters as participant-level analytics

## After

- [ ] Ask all debrief questions
- [ ] Stop/delete any unapproved recording
- [ ] Export anonymized observations
- [ ] Remove synthetic enrollments and facility sessions or restore clean test state
- [ ] Do not include names or personal details in findings
